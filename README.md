# Pusher (pusher)

Pusher is a realtime communication platform. Its primary product Channels provides pub/sub messaging over WebSocket and HTTP; Beams provides device push notifications. Chatkit was sunset.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/pusher/refs/heads/main/apis.yml)
